# Changelog

## 1.0.0 — release candidate, not yet published

Mosaic Template Studio turns downloaded artwork into full-color, actual-size mosaic templates on Windows, with English and Polish interfaces.

- Enter finished dimensions in inches, preserve proportions, or choose Fit, Crop or Stretch.
- Preview Letter tiles with automatic minimum-sheet orientation; print directly or export a tiled PDF from the same physical layout.
- Use conventional enlargement or bundled offline CUNet enhancement, with original/enhanced comparison and CPU fallback.
- Save editable, self-contained projects with recovery, recent projects and undo/redo.
- Install per user with the runtime, workers, models, notices and Desktop/Start shortcuts included.

Final QA corrected calibration printer persistence, Standard-image cache verification, native import/shutdown cancellation and diagnostic path privacy. Installer verification now cleans up failed test installations. CI checks PDF dimensions and Windows print preparation alongside geometry and storage.

Production publication is blocked by outstanding target-device and human acceptance. See the [release report](docs/RELEASE_READINESS.md) for exact software evidence and remaining gates. The installer is unsigned; printed accuracy has not been physically certified.
